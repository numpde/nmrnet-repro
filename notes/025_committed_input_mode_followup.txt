selected Git commit. They no longer compare each live file's executable bits
with that commit. Live bytes and path types remain checked; Git status may still
report mode-only changes when the repository tracks file modes.

there is evidence that the committed capture is insufficient. Any future
check should name the affected executable and avoid adding per-file probes to
inputs that are interpreted rather than executed directly.
