SMILES protocol admission, 2026-10-19
====================================

nmrnet_provider/smiles_protocol.py now encodes the exact UTF-8 source/count and
frozen native collection. UTF-8 JSON text preserves original bytes without base64
expansion. No work-budget fields are accepted from a request. The receiver checks
caller-owned source SHA/count/settings, ordered unique actual IDs, executable
angstrom requests and complete source/runtime/stereo evidence with valid atom
references. It does not reparse SMILES, add H or recompute stereochemistry.
Source correspondence is a producer qualification obligation; internal reference
checks do not prove that the source was chemically interpreted correctly.

The encoder derives success/shortfall from the one requested/returned count pair;
there is no independently supplied disposition flag. A valid shortfall reconstructs
ConformerShortfall with the exact full private partial, never successful input.
Malformed replies preserve their decoded contents privately in WorkerResultRejected.
The complete frame, including escaped metadata and diagnostics, is admitted before
returning an encodable reply. Overflow retains the exact original batch on a typed
private exception; nothing is clipped or emitted as a successful prefix.

The explicit make test/unit/smiles-protocol lane uses the established
tests/unit/normative and tests/unit/adversarial split. Its authored protocol data
are not a native scientific reference. The pinned native generator lane separately
checks that a real generated collection survives framing/admission unchanged and
that decoding cannot regenerate it.

No generation client/server operation is exposed in this slice. A frame-overflow
exception retains data only in process; it is not durable capture after worker
exit. Review of tools/worker_qualification.sh / tools/inference_native.sh found the
existing 64-block output file limit (32 KiB) cannot retain a >2 MiB generated
collection in stderr, and geometry qualification does not preserve that capture
as payload evidence. Do not silently repurpose retirement-control directories.
The next composition must provide a bounded full-output transport/evidence owner
or establish pre-generation aggregate capacity before exposing the operation.
The existing 2 MiB frame remains the authority; no arbitrary smaller N cap is added.

Validation: 12 focused normative/adversarial unit cases and 11 pinned native cases

MOL2 coordinate projection, 2026-10-19
=====================================

The selected implementation is pure nmrnet_provider/mol2.py, sharing existing
decode_source/prepare_rows/unit admission with other readers. NMRNet consumes
elements and XYZ; no native graph/charge perception is needed to obtain those
fields. This supersedes the tentative RDKit-MOL2 path in 015/016 without weakening
source preservation or worker/container qualification. The source is retained by
whole-file digest, original record ordinal and original integer ATOM IDs in file
order. No bond, charge, isotope/stereo or alternate-attribute interpretation,
molecular-equivalence check, atom reordering or H completion is performed.

Tripos, Tripos Mol2 File Format, SYBYL 7.1 (Mid-2005), printed/PDF pp. 3, 12 and
53-54 owns section framing, ATOM rows and concrete SYBYL type interpretation:
https://zhanggroup.org/DockRMSD/mol2.pdf#page=3
https://zhanggroup.org/DockRMSD/mol2.pdf#page=12
https://zhanggroup.org/DockRMSD/mol2.pdf#page=53
The complete concrete dotted vocabulary has 27 entries, represented by small
per-element suffix sets; unknown suffixes never become elements by prefix guessing.
Two real sulfur spelling aliases, S.o/S.o2, are explicit extensions supported by
MDAnalysis 2.9.0 SYBYL2SYMB and Open Babel 3.1.1 MOL2Format::ReadMolecule:
https://docs.mdanalysis.org/2.9.0/_modules/MDAnalysis/guesser/tables.html
https://github.com/openbabel/openbabel/blob/openbabel-3-1-1/src/formats/mol2format.cpp#L269-L272
The manual's extracted text uses uppercase O; no rendered-image verification was
possible. The independent published mappings agree with uppercase forms and also
support the two lowercase aliases. This is not general case folding. Bare element
spellings beyond the table are a declared extension; the existing request parser
and later model dictionary own usable element admission. Pseudo/query types and
D/T labels request correction rather than creating/removing a supplied nucleus.

requirements/preparation.md retains the complete reference pages/sections and
precise native research chain (RDKit issue 9421 -> PR 9417 -> released changelog),
with unavailable advisory, older-source and binary/source identity limits. It does
not mistake Open Babel advisories for RDKit issues or clear the separate V3000
block. Avoiding the native MOL2 graph parser is a product-boundary choice, not
evidence that the retained toolkit is safe or unsafe for that path.

Framing covers the whole bounded source; section markers start with @ in column 1.
Only selected ATOM rows/types/counts are parsed. BOND/SUBSTRUCTURE/attribute content
is opaque. Selected ATOM rows must occupy one physical line; unsupported wrapped
rows request correction. A failed selected record returns no successful prefix;
