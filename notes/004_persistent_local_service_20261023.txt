Original ownership and state
-----------------------------
Each systemd INVOCATION_ID selects a fresh private runs-root child. A nonblocking
lock on the runs root serializes different service instances that accidentally
select the same root. RUNS_ROOT/current binds the previous installation to its
original host-retired receipt. A previous unconfirmed/missing receipt or orphaned
root evidence refuses startup before engine effects. The original host writes
that receipt only after exact original grants/containers and its engine client
have retired. This does not introduce recovery authority over old worker trees.
The current runtime symlink is only a status/log locator and disappears on reboot;
a startup refused before recreating it reports its prior path in the host journal,
with retained IDs available for the existing provider/logs filter. Per-installation locks,
native receipts and durable Attempt effects keep their existing owners.
No directory fsync/power-loss or filesystem-quota guarantee is claimed here.

The user unit sends TERM to the main host owner, has no forced KILL and retains
an unlimited manager stop window. Restart=no prevents automatic repetition over
an uncertain original lifetime. Stop requests are asynchronous: acknowledgement
is not proof of completed drain; status reports the actual manager state.
Native prediction recovery remains with its already qualified bounded owner.
Finite30s manager-client deadlines bound operations without turning client timeout
into proof of manager-side outcome. Logs reuse bounded host/Docker journals; no
stream-file fallback, transcript dump, second diagnostic journal or engine-socket
grant to the controller is added.
