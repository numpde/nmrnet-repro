Documentation and retained data

The maintained prose lives in these HTML pages. The short root README points here; there are no parallel Markdown guides or document-generation step. Historical records retain dated decisions and evidence separately from current instructions. Literal record text keeps its original line anchors and commit-pinned citations, including paths used at the time. Page metadata identifies each record's previous source and revision.

The non-HTML text exceptions are the root README.md, the machine-read source manifest containers/inference/image-inputs.txt, and the scientific fixture tests/fixtures/small_chloromethanes.txt. JSON manifests, lockfiles, configuration examples, source comments and legal notices remain in their native formats. The pinned upstream submodule is unchanged.

Frozen scientific inputs and expected-output files retain their original bytes, including historical documentation paths. The current fixture explanation is Structure-reading and SMILES fixtures; moving documentation does not authorize changing an independent numeric oracle.
