Provider consumer tests

NMRNet tests its use of the released shared package. Generic core, proxy, queue and host delivery tests belong to nmr-provider-tools.

Installed consumer

make test/integration/provider-core WHEELHOUSE=/path/to/shared-wheelhouse
make test/integration/provider-core/config WHEELHOUSE=/path/to/shared-wheelhouse
make test/integration/provider-core/compose WHEELHOUSE=/path/to/shared-wheelhouse
make test/integration/provider-core/runtime WHEELHOUSE=/path/to/shared-wheelhouse
make test/integration/provider-core/delivery WHEELHOUSE=/path/to/shared-wheelhouse

These offline lanes install the pinned wheel into an ephemeral environment and load NMRNet's scientific bindings. Reusable fake peers come from selected regular files in the hash-pinned source archive. Core source and generic test cases do not enter consumer discovery. The selected wheelhouse is mounted read-only.

Image and scientific proof

make test/integration/provider-runtime checks the built controller's distribution inventory, signing support, isolated imports and dependency evidence. Geometry, prediction and numerical reference qualification have their own reproduction commands. A passing controller test does not establish model accuracy or successful delivery on a deployed API.

API qualification

The opt-in API targets exercise the normal deployment owners. They require explicit API credentials, routes and private output. A target that creates a Job produces a persistent API record; it is excluded from offline aggregates. GUI behavior is outside this repository's test boundary.
