Shared provider core

nmr-provider-tools owns the reusable provider package, result delivery service, network proxies and host delivery deployment. NMRNet installs its released provider-core wheel; it owns molecular input preparation, NMRNet++ execution and scientific results.

Release and installation

The 0.2.1 release supplies the wheel, source archive, full installation lock and provenance record. NMRNet pins the GitHub artifact URLs and hashes and consumes the released installation lock offline. The source archive supplies reusable test fakes; consumers do not rebuild the package or import another checkout. See dependency inputs.

Delivery ownership

A provider retains a selected terminal request in memory until the shared service acknowledges durable intake. After acknowledgment, the service owns publication, retry and recovery of those exact bytes. It deletes a queued payload only after a verified matching API receipt or an explicit operator discard. Intake acknowledgment is not API completion.

A crash before durable intake can leave the remote Attempt unresolved. Restarting a provider does not repeat scientific work to manufacture a replacement result. The provider and delivery service reconcile their existing records with the API. See result delivery and storage.

Shared configuration

One operator-owned binding definition supplies API identity, credentials, route and socket grants to both deployment owners. NMRNet derives those runtime settings from the selected binding. Its own definition supplies scientific policies, interpreter and Upload settings, producer retry budgets and execution limits.

Run the delivery service through the shared repository's maintained commands. Run NMRNet through its provider deployment commands. Operator-owned configuration and separate secrets are read-only inputs; shared queue and socket state stays in Docker volumes, without a generated host tree. Each owner controls its containers and storage; stopping NMRNet leaves shared delivery available to other providers.

Qualification

The shared owner qualifies core protocol, storage, proxy and deployment behavior. NMRNet checks its installed-package integration and scientific contracts. The consumer test guide describes those boundaries; API fixture provenance records the pinned contract evidence.
