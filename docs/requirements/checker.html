Offline checker dependencies

The checker image is dedicated to offline repository proof. Unit/archive lanes keep the existing Python base. Acquisition is explicit and uses tools/docker.sh with its admitted interface and loopback proxy; image installation uses only verified local artifacts with build networking and pulling disabled.

The declaration is checker-dependencies.json, with schema, exact base digest, linux/amd64, and a closed package inventory. Every entry owns name, version, filename, official URL, byte size and SHA-256. The existing pinned base is Python 3.12.12 slim Bookworm at digest 593bd06efe90efa80dc4eee3948be7c0fde4134606dd40d8dd8dbcade98e669c.

The direct tools are Debian Git 1:2.39.5-0+deb12u3, Make 4.3-4.1, and Ruff 0.15.15. Ruff's exact version is owned by the imported SECS gate: https://github.com/numpde/secs-repro/blob/34f5915c1534278bbf61b4c6592afa44cf94ab08/secs/.github/workflows/ci.yml

Official package pages describe Git/Make: https://packages.debian.org/bookworm/git https://packages.debian.org/bookworm/make The inventory was resolved on 2026-10-14 against authenticated Debian Bookworm, Bookworm updates and Bookworm security amd64 indexes. Native apt simulated --no-install-recommends install git=1:2.39.5-0+deb12u3 make=4.3-4.1 against the pinned base's unchanged dpkg status. It selected 18 new packages and the required perl-base upgrade from 5.36.0-7+deb12u3 to 5.36.0-7+deb12u4. The declaration therefore contains 19 Debian artifacts and one Ruff wheel. This is the complete addition set relative to the pinned base; inherited dependencies remain supplied by that exact base, whose package inventory was captured. Recommended and suggested packages are excluded.

Debian versions, filenames, sizes and SHA-256 values come from apt's authenticated package stanzas. Security-pool artifacts use /debian-security/pool/updates/main/; ordinary artifacts use /debian/pool/main/. Apt verified the signed catalogs using the pinned base's /usr/share/keyrings/debian-archive-keyring.gpg, and a separate offline gpgv pass verified all three retained InRelease files. Catalog hashes, signature fingerprints and dates are recorded in checker-advisories.json. Offline builds capture the recipe, declaration, verifier and dependency bytes before dispatch. Image publication requires the actual local immutable ID and matching captured-input label. No Git database, engine socket, secrets or model data enters this tool-only image. Ordinary checks receive their reviewed sources from the runtime launcher rather than copying a whole checkout into the image.

The checker deliberately uses the selected local engine's built-in Dockerfile frontend, matching the qualified inference/lock recipe boundary. It has no external syntax directive: runtime network flags and --pull=false do not stop an independent frontend-image fetch. The builder is explicitly default, with ambient builder/config/backend selectors removed. Engine 29.8.1/API 1.56 was observed locally; a real offline named-context/RUN-mount capability probe passed before actual installation. The exact command, immutable probe image and installed version checks are retained in .work/qualification/checker-foundation-20261014/materialization/REPORT.md. No external frontend image is provisioned.
